# 📻 Radio Universal

**Radio Universal** es una experiencia web interactiva para escuchar estaciones de radio en vivo desde tu navegador. Basada en la versión desplegada en [radiouniversal.netlify.app](https://radiouniversal.netlify.app), este proyecto busca ofrecer una interfaz moderna y ampliable para descubrir y reproducir estaciones de radio por Internet.

---

## 🎵 ¿Qué ofrece actualmente?

- Reproducción en vivo de múltiples emisoras de radio
- Controles básicos: play/pausa, volumen, selección de estación
- Interfaz responsiva y simple, optimizada para desktop y móvil
- Despliegue inmediato y sin necesidad de instalación gracias a Netlify

---

## 🌍 Inspiración: la versión original

La web original es una demostración funcional que permite explorar estaciones de radio fácilmente. **Radio Universal** toma esa base y propone:

- Organización del código en componentes claros
- Mejora en la UX con estados de carga y manejo de errores
- Refactorización para facilitar futuras adiciones

---

## 🚧 Tecnologías utilizadas

- **React.js** o **Vue.js** *(ajusta según el framework que utilizaste)*
- CSS puro o **Tailwind CSS** para estilos
- **HTML5 Audio API** para reproducción de audio
- JavaScript ES6+
- Despliegue en Netlify
